# 怎么开通「云端编译复核」（PAT 与仓库名）

> 一句话：这一步**不做也能继续产**。做了只是多一道云端独立复核，让每个函数多一层保险。
> 不影响日产 300 的目标，不用着急。

---

## 一、先把两个词翻译成人话

| 名词 | 人话 |
|---|---|
| **PAT** | GitHub 的**个人访问令牌**。可以理解成"给程序用的一次性密码"。你不想把账号密码交给脚本，就生成一串字母数字，程序拿它上传文件；用完随时可以作废。 |
| **仓库名** | GitHub 上**一个项目文件夹的名字**，长这样：`zhangsan/daoli-library`。斜杠前面是你的 GitHub 用户名，后面是项目名。 |

为什么要它：我们的代码现在只在你本机 `C:\Library`。GitHub 相当于一个**免费云服务器**，把代码推上去后，它会自动开一台机器、装好 C 编译器、把 1252 个函数从头编译一遍。这是本机做不到的（本机缺 gcc/bison/flex，装不上）。

---

## 二、三步操作（大约 5 分钟）

### 第 1 步：建仓库

1. 打开 https://github.com ，登录（没有就注册一个，免费）。
2. 右上角 **+** → **New repository**。
3. **Repository name** 填 `daoli-library`（名字随你，记住它）。
4. 可见性选 **Private**（私有，别人看不到）或 **Public**（公开，免费额度更大，但我们建议先 Private）。
5. **不要**勾选 "Add a README file"。
6. 点 **Create repository**。

建好后，浏览器地址栏会变成 `https://github.com/你的用户名/daoli-library`。
**把这个地址记下来** —— 它就是"仓库名"，格式 `你的用户名/daoli-library`。

### 第 2 步：生成 PAT

1. 打开 https://github.com/settings/tokens
2. 点 **Generate new token** → 选 **Generate new token (classic)**。
3. **Note** 随便写，比如 `daoli-ci`。
4. **Expiration** 选 `90 days`（90 天后要重新生成，到期前我会提醒）。
5. **勾选权限**（只勾这两个就够）：
   - ☑ `repo`（整组，读写代码）
   - ☑ `workflow`（让程序能触发云端自动编译）
6. 拉到最下面点 **Generate token**。
7. 页面会显示一串 `ghp_xxxxxxxxxxxx`。**这串只显示一次**，关掉就再也看不到。

### 第 3 步：把令牌存到本机（不要发在聊天里）

1. 按 `Win + R`，输入 `notepad`，回车打开记事本。
2. 把那串 `ghp_...` 粘进去，**只粘这一行**，不要有空格和换行。
3. 另存为：路径填 `C:\Library\_tools\.gh_token`，保存类型选「所有文件」。
4. 保存。

这样令牌只在你本机，不会进聊天记录，也不会进 git 仓库（已被 .gitignore 排除）。

## 三、然后告诉我一句话

跟我说：**"仓库名是 你的用户名/daoli-library，token 已存好"**。

我会执行一条命令，自动完成：验证令牌 → 配置远端 → 首次上传 → 触发云端编译 → 读回结果。之后每轮任务收尾都会自动推送，你不用再管。

## 四、不做的后果（很轻微）

| 能力 | 不配 PAT | 配了 PAT |
|---|---|---|
| 本地编译闸（RuSTy，逐件必过） | ✅ 正常 | ✅ 正常 |
| 入库、JSONL、文档、战报 | ✅ 正常 | ✅ 正常 |
| 日产 300 目标 | ✅ 不受影响 | ✅ 不受影响 |
| 云端 MatIEC 第二道独立复核 | ❌ 缺 | ✅ 有 |
| 代码异地备份（防本机损坏） | ❌ 缺 | ✅ 有 |

**唯一实质损失**：只有一个编译器的意见（RuSTy）。配了之后是两个不同编译器交叉验证，漏检率会再降一档。

## 五、常见疑问

**Q：令牌会不会被盗？**
它是本机文件，权限只到你自己那一个仓库。90 天自动过期。真出事可在同一页面点 Delete 立刻作废。

**Q：一定要 Private 吗？**
Private 更安全，但云端自动编译的免费额度可能受限。如果发现云端不跑，把仓库改成 Public（Settings → 最下面 Change visibility）即可，代码本身不含任何机密。

**Q：以后换电脑怎么办？**
重新走第 2、3 步生成新令牌即可，仓库和数据都在云端，不会丢。
