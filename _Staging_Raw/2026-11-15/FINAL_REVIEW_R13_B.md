## B1 ｜ FC_DL_BitArrayRotate（DL_Base）

**规格对照**：签名、常量（DL_BAR_MAXW=4 / DL_BAR_WBITS=32）、故障码表（013D/013E/021F）与规格 §3.2 B1 逐项一致。实现取「整字偏移 k + 字内偏移 r」双移位合成路径，规格未规定具体实现法，属合法实现自由度。

**独立验算**：
- V1 左移 1 → `[0x00000002, 0x00000001]`、V2 右移 1 → `[0x40000000, 0x80000000]`、nEffectiveShift=63，实算一致；
- V3 nShift=64 两字整圈 → 归约 eff=0、输出等于输入、置 013D，一致（整圈也报「被归约」，符合规格 V-B 精神）；
- V4 nWords=0 → FALSE / 021F / 目标数组零写入（早退先于任何 aDst 写入），一致；
- 位守恒：3000 组随机（1~4 字、左右方向、移位量 −200~200）旋转前后 1 的个数全部不变，且与整数级参考循环移位实现逐组一致——跨字回卷、字序（第 1 字承载位 0~31，LSB 起）、方向归一（负值恒右移）全部验证正确；
- `SHL/SHR` 移位量域被结构性限制在 1~31，无 64 位移位未定义行为；r=0 整字搬运分支规避了 `SHR(x,32)`。

**偏离裁定**：① 规格注释「移位位数 −127~127」与「MOD 归约」并存，实现在 |nShift|>127 **或** 跨越整圈时均报 013D（信息级）——比规格字面更严格，**采纳**；② 双信息码（013E 钳位与 013D 归约）同拍冲突时按段序优先级只保留先发生者，符合 §3.0 ③ 码位单一优先级链，**采纳**。

**缺陷**：无。
**升版**：无（维持 v1.0.0）。
**终审判定**：**PASS**

## B4 ｜ FC_DL_StringToLReal（DL_MathData）

**规格对照**：签名、DL_S2N_MAXLEN=40、码位（0143~0146 / 0222 / 0223）逐项一致；R38 合规——`nLen := LEN(sText)` 入口一次锁存，全文循环上界/下标/消费计数均取自副本；R37 镜像面合规——无 LEFT/MID 回夹拼值。逐字符状态机含兜底分支（非数字非符号非点一律判非法），终态校验拦「只有符号 / 只有小数点 / 只有指数标记」半截输入。

**独立验算**：
- V1 `-12.5` → TRUE / −12.5 / 消费 5 / 错位 0；V2a `1.5E3` → 1500.0；V2b 禁指数 → FALSE / 错位 4 / 0144 / 前缀值 1.5 保留；V3 `12.5.3` → FALSE / 0222 / 错位 5 / 消费 4——全部与规格一致；
- V4 `1E40` → 指数 40 超 38 保护域 → 0146、值落有限上界后夹到 fMax=1E30、不输出 Inf，一致；
- V6 `1E30` 上限 100 → TRUE / 100.0 / 0145（夹域不算失败，返回条件 `bOk AND (码=0 或 0145)` 与规格口径一致）；V7 全空白 → 0143 / 消费 0；
- 边界补充验算：`+`（只有符号）→ 0143；`1E-3` → 0.001；`1 2`（嵌入空白）→ 0144 错位 2——容错行为正确；
- 除法面：尺度分母恒 ≥1.0、指数除数恒 ≥10.0，全部判零后除；指数累加 3 位封顶保证幂次循环上界 ≤38；0223 非有限拦截式可同时捕获 Inf 与 NaN。

**偏离裁定**：① 有效数字 18 位封顶后（超出 LREAL 精度）后续数字不再累计、也不计入小数位——只损失超精度位，对 LREAL 无语义影响，**采纳**（注释已写明 DL_S2N_SIGMAX 上限保护意图）；② 形参串长用字面量 40 与常量 DL_S2N_MAXLEN 双处对齐（IEC 类型声明不接受 POU 内常量），已在头注释「偏离留档」声明，**采纳**。

## B6 ｜ FC_DL_Matrix3Inverse（DL_MathData，Matrix 子族开族）

**规格对照**：签名、相对奇异判据 `|det| ≤ fDetEps × maxAbs³`、码位（014A~014C / 0225）逐项一致；伴随矩阵法九个分子**逐项手算复核**：aW[1]=ei−fh、aW[2]=ch−bi、aW[3]=bf−ce、aW[4]=fg−di、aW[5]=ai−cg、aW[6]=cd−af、aW[7]=dh−eg、aW[8]=bg−ah、aW[9]=ae−bd，与代数余子式转置（adj = Cᵀ）完全一致，**无元素符号写反、无转置错位**；行列式按第一行展开 `a·C11 − b·C12 + c·C13` 正确。

**独立验算**：
- V1 单位阵 → 逆=自身 / det=1；V2 对角 2/4/5 → 逆 0.5/0.25/0.2 / det=40，一致；
- V3 `[1 2 3; 2 4 6; 7 8 9]` → det 精确为 0 → 相对判据（0 ≤ 1E-9×729）判奇异 → FALSE / 0225 / afInv 全 0，一致；
- V4 整体 ×1E-6 → 中间项量级 ~1E-17 级、消元后 |det|≈1.2E-32（舍入噪声），相对判据 |det|/maxAbs³≈1.7E-17 ≤ 1E-9 → 仍判奇异——**绝对判据在此量纲下会失守的场景，相对判据正确拦截**，V4 的存在意义得到实算确认；
- A×A⁻¹≈I：500 组随机可逆矩阵（容差 1E-6）乘积全数逼近单位阵——伴随分子与行列式联合正确性的最强实证；
- V5 非有限元素 → 014B / FALSE / afInv 全 0（段 1 逐元素预置保证，不输出 NaN）；V6 容差 0 → 014C / 默认 1E-9 继续 / 返回 TRUE；V7 病态提示路径判据（`fCondEst < 1E-3 AND fCondEst > 10×fEps`）与规格一致；
- 除法面双锁：段 6 相对判据 + 段 7 显式 `fDetR > 0 OR fDetR < 0`，逆元素逐个过有限性检查再 LIMIT 夹域（R43 精神合规）。

**缺陷**（1 项，文档级，非逻辑级）：

| # | 严重级别 | 位置 | 描述 | 处置 |
|---|---|---|---|---|
| B6-D1 | 轻微（文档） | 头注释验收向量 V7 | 称「条件数粗估约 1.0E-18」，实算 `fCondEst = \|det\|/maxAbs³ = 1E-6/1³ = 1.0E-6`（编码者误把阈值 `fEps×scale=1E-12×1` 记成了 fCondEst）。V7 的判定结论（码 014A、逆已给出）不受影响——1.0E-6 同样落在「超 10 倍容差、低于 1E-3」区间 | 已修复，升版 v1.0.1 |

**升版**：**v1.0.0 → v1.0.1**（仅头注释 V7 数值勘误 + 修订历史追加，判定逻辑与码位零改动）。
**终审判定**：**PASS**（v1.0.1）

**观察项（不构成缺陷，登记备查）**：当矩阵元素量级接近 ±1E150 时，余子式乘积可能溢出 LREAL 使 fDetR 呈非有限——现有有限性检查会发布 fDet=0 且逆元素经有限性检查归零，不会输出毒值；规格未定义该场景码位，本轮不改，留 ROADMAP 备选（如后续立「行列式溢出」信息码）。
