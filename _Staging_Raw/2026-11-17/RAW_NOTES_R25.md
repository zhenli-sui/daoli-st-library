## 2. 序号 2 的数值口径落纸（防编码侧自造）

- 等级上限 = `Cn(N, D) = 10^N × (0.1/D)^2.08`，`D = 0.1 / 0.2 / 0.3 / 0.5 / 1.0 / 5.0 μm`，`N ∈ [1, 9]`，允许 0.5 级。
- **实现方式裁定：用常量表，不用实时幂运算。**
  - 理由一：IEC 61131-3 的 `**` 运算符在三目标平台支持不一致（CODESYS 支持 `EXPT`，部分平台仅标准库函数），实时幂运算引入可移植性风险；
  - 理由二：标准表值本身是「公式算完取整」的离散值，用表即与验收口径一致，避免「公式重算值 vs 标准表值差 1 颗」的争议。
- 表值取自公开资料的 ISO 14644-1:2015 Table 1（≥0.1/0.2/0.3/0.5/1.0/5.0 μm × Class 1~9，共 54 格，「—」格 = 不参与判定）。
- `DL_` 常量命名建议：`DL_ISO14644_LIMIT : ARRAY[1..9, 0..5] OF LREAL`（无量纲颗/m³），「—」格填 `-1.0` 作为「不参与」哨兵，**禁止填 0**（0 会被误判为「最严等级」）。
